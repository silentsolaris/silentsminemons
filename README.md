Silent's Minemons!
----------------------------------
This addon aims to add fakemon inspired by VANILLA minecraft mobs, mob vote losers and other official minecraft related content while not being too blunt!

These fakemon aren't just a 1-to-1 of a mob but pokefied, 
but something I believe could actually fit with the existing dex of Pokemon from 'vanilla' cobblemon!

This Pack takes a lot of time and effort, which I do for free. If you want to help continue this project, or if you want to commission me, then [buy me a coffee!](https://ko-fi.com/silentsolaris) It would really help me out!

Check the [Modrinth Page](https://modrinth.com/datapack/silents-minemons) or the [Wiki](https://github.com/silentsolaris/silentsminemons/wiki) for more information!
